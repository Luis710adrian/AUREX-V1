# Phase 2 — Money & Capacity

Technical plan: extend the slice with effective-dated rates, expense approval,
capacity computation, budget/margin completeness attestation and real AR aging.
Money remains numeric. Invoice status is a consequence of payments, never a form.
Acceptance: partial/full payments, overpayment denial, rate snapshots, expenses
approval/audit, capacity minus absences, actual financial filters and drill-down.
P&L recognition, forecasting, tax/CFDI integration and scenario planning require
separate implementation and tests before phase acceptance.
