# Phase 1 — Operating Core

Technical plan: expand validated core transactions into phase gates, risk/issue
separation, notification inbox and assigned-work views. Keep the six AUREX phases
ordered; require evidence and review before advancing. CRM and project details
remain linked, without recapturing company/contact.
Acceptance: persistent gates and audit, denied out-of-order transitions, project
membership isolation, task state changes, owner notifications, files/versioning
with internal QA, calendar/Gantt, and browser demo. The last three requirements
must remain pending until implemented and tested. This plan does not waive them.
